# 행동 선택 그림 파일

각 동물의 행동 상황을 하나의 독립 PNG로 분리했습니다. 아틀라스 배경 위치로 잘라 표시하지 않습니다.

- 원본: work/action-atlases/{push,throw,shout,hold,hurt}.png
- 각 원본: 2172×724, 왼쪽부터 몽·루루·부기 상황 3개
- 최종 파일: 748×748, 상황 주변 12픽셀 투명 여백
- 함께 등장하는 토끼·소품·효과도 상황의 일부로 보존
- 15개 파일의 상하좌우 테두리 알파 0 확인
- 원본 생성 프롬프트·도구 메타데이터는 이 작업 폴더에 없어서 복원하거나 추정하지 않았습니다.
- hold 원본의 구름은 원본 캔버스 상단에 닿아 있습니다. 분리 작업은 원본의 그림을 새로 그리거나 복원하지 않았습니다.
